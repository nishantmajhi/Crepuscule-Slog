How this avoids re-running Claude

01 - Skill writes JS

Claude's docx/xlsx/pptx skills already generate plain Node scripts using the docx, exceljs, or pptxgenjs packages. That script is the entire file - nothing else is needed to rebuild it.

02 - Crepuscule Slog loads the same libraries

This page pulls the identical browser-compatible builds of those packages from a CDN, once, and keeps them in memory for the tab.

03 - Your code runs locally

Pasted code executes right here against those libraries. No server round-trip, no second Claude session, no extra inference cost.

npm mode: paste the script as Claude wrote it for that skill - a Node-style file ending in something like Packer.toBuffer(doc) (docx), workbook.xlsx.writeBuffer() (xlsx), or pptx.writeFile(...) / pptx.write(...) (pptx). Crepuscule Slog intercepts the save call and turns it into a download instead of a filesystem write.

XML mode: if Claude got stuck and left raw XML instead of a script, switch to the XML option in the dropdown and paste the XML directly - Crepuscule Slog wraps it in a minimal Office Open XML zip and downloads the finished file.
